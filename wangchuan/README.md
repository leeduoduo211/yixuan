# 硅谷王川语录与文章收录

本目录收集整理硅谷王川（Chuan Wang）在公众号 `investguru`、新浪博客、财新博客"兵无常势"、微博、Twitter(@Svwang1) 以及个人网站 [chuan.us](https://chuan.us/) 等平台发布的语录、文章与思想摘录。

## 关于作者

王川，独立投资人，中国科学技术大学少年班 87 级校友，罗切斯特大学材料科学硕士、佐治亚理工学院计算机科学博士，现居美国加州硅谷。自 2015 年起通过微信公众号 `investguru` 持续输出原创财经、科技、思维方法与人生感悟类文章，总量超过 200 篇。其部分内容被粉丝整理成《王川宝典》《个体破局》等电子书，被读者誉为"中国版纳瓦尔宝典"。
